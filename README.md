Vice Horizon: Neon Syndicate is an open-world crime game built in the spirit of GTA 6. Explore a sprawling neon metropolis on foot and by car, hijack supercars, navigate dynamic traffic and pedestrian crowds, evade escalating 5-star police pursuits, and complete high-stakes syndicate heist contracts with a complete radar minimap HUD.

## Run it

Serve locally:
```sh
node serve.ts
```
Then open `http://localhost:8080` in a desktop browser.

Build output dossier:
```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
